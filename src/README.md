# `src/`

Source map for the Giftistry React client. Nested READMEs get more local as you descend.

## Layers

| Folder | Role |
|--------|------|
| [app/](app/README.md) | Bootstrap, routing, layout, pages, app providers |
| [features/](features/README.md) | Domain UI + hooks (barrels) |
| [shared/](shared/README.md) | Primitives, utils, shared providers |
| [core/](core/README.md) | API client, env, theme helpers (no UI) |
| `assets/` | Global styles and static assets |
